## 便宜机场怎么选：月付、不限时与按量付费

<details>
<summary>展开：低价机场的比较方法与购买风险</summary>

找便宜机场，先看自己多久用一次，再看流量和付款周期。低价只是费用信息，不能说明服务质量。

| 你的情况 | 可以先比较什么 | 购买前确认 |
|---|---|---|
| 每个月都有固定用量 | 月付机场套餐 | 每月流量、重置日期、超额后的处理 |
| 偶尔使用或作为备用 | 不限时、按量付费套餐 | 流量和账户是否有到期或清理规则 |
| 打算长期使用 | 月付与季付、年付的实际总成本 | 预付金额、退款条件、服务中断风险 |

“按量付费”和“不限时”不是同一个条件。前者描述计费方式，后者描述有效期；购买流量包时仍要分别确认这两项。“不限时”也不代表服务永久运营。

表格中的最低月付价，应是可以实际按月购买的套餐。年付折算每月几元，仍需要一次支付年费，不能与月付混写。优惠价还要看有效期、适用套餐及续费是否恢复原价。

第一次使用，可以先比较小额或短周期套餐。大流量、长周期套餐即使折算单价较低，也会增加预付金额。服务可能调价、中断或停止运营，不要把尚未使用的余额和流量当作有保障的资产。

下单前再核对四项：退款条件、设备或连接数限制、限速规则、客服入口。没有写清楚的地方先问服务方，不把“未说明”理解成“无限制”。

</details>

## 续费、流量重置、套餐覆盖与付款未到账

<details>
<summary>展开：这些操作可能改变不同的东西</summary>

付款前看清订单说明，尤其是以下几种情况：

- **续费**：确认它延长的是哪个套餐、从哪天计算，以及是否同时补充流量。
- **流量重置或加购流量**：确认增加多少可用流量，以及原到期日是否变化。
- **更换套餐**：确认新套餐何时生效、旧套餐剩余价值如何处理，是否覆盖原有流量。
- **叠加套餐**：只有服务方明确支持时，才按可以同时保留多个套餐来理解。

例如，某套餐月底到期、流量已经用完。如果“重置流量”的说明写着不延长有效期，那么补充的流量仍需在原到期日前使用；如果续费只延长时间、不立即重置流量，续费后也未必马上能继续用。这里是规则示例，不代表上表所有商家的做法。

**已经付款，套餐却没生效怎么办？**

先保存订单号、付款时间和交易凭证，对照账户里的订单状态。不要因为页面没刷新就连续重复支付；通过原站工单或已确认的客服入口询问处理方式。如果交易显示失败，也先核对支付渠道是否实际扣款。

公开求助时遮住邮箱、订单中的个人信息和支付凭证细节。不要把账户密码、验证码或完整订阅链接发到群聊，也不要把客服处理描述成一定可以退款或一定能到账。

</details>

## VPN、代理和机场有什么区别？

<details>
<summary>展开：先分清技术、客户端和服务商</summary>

VPN 是组建虚拟私有网络的技术。例如 WireGuard 通过加密隧道在 UDP 上承载 IP 包。代理则代表客户端转发连接或数据，SOCKS5 是其中一种代理协议。两者覆盖哪些流量，取决于协议、客户端和路由配置；VPN 也可以分流，不一定接管所有流量。[WireGuard 说明](https://www.wireguard.com/)、[SOCKS5 标准](https://www.rfc-editor.org/rfc/rfc1928)、[OpenVPN 全隧道与分流](https://openvpn.net/as-docs/tutorials/tutorial--full-and-split-tunnel-vpn/)

本指南把“机场”作为提供节点订阅等服务的商家俗称，不把它当作一种协议或质量认证。客户端是安装在设备上的软件，订阅是它读取配置的一种方式，服务商则提供相应网络服务。

手机状态栏出现 VPN 标识，不能单凭这个图标判断正在使用哪种代理协议。例如 Android 的 VpnService 提供虚拟网络接口，具体怎样处理其中的数据由应用实现。[Android VpnService 文档](https://developer.android.com/reference/android/net/VpnService)

不要简单理解为“VPN 都不好用”或“机场一定更安全”。是否适合自己的用途，需要分别看线路、协议支持、软件维护、服务方可信度和实际使用条件。VPN 或代理也不能自动防止钓鱼、恶意软件和所有账号追踪。[EFF 的 VPN 选择指南](https://ssd.eff.org/module/choosing-vpn-thats-right-you)

</details>

## 免费机场、公共订阅与共享账户有什么风险？

<details>
<summary>展开：免费不等于可信，付费也不是安全保证</summary>

公开订阅能导入、节点能连上，只能说明当时具备一定可用性，不能证明运营者可信、隐私政策可靠或服务能持续。

本页不提供来源不明的免费订阅和共享账号。准备尝试公开资源时，至少核对：

- 谁在维护，是否有能核实的项目或服务说明。
- 是否要求额外安装软件、证书、脚本或描述文件。
- 配置包含哪些代理、DNS 和路由设置，更新时是否会改变。
- 是否有流量、连接数、有效期和使用场景限制。

VPN 或代理会让部分信任从原网络转移到服务提供者。HTTPS 能保护正确加密连接中的内容，但不等于隐藏所有连接信息；也不能用“已开代理”代替安全的账户和设备习惯。[EFF 的 VPN 选择指南](https://ssd.eff.org/module/choosing-vpn-thats-right-you)

不了解来源的网络服务，不适合作为承载敏感业务的默认连接。付费服务同样需要检查运营者、条款和隐私说明，不能只靠收费与否判断。

完整订阅地址可能包含访问凭证，应按敏感信息保管。不要贴到公开仓库、截图或不可信的在线转换网站；如已泄露，按服务方提供的方式撤销或重置，并确认其他设备是否需要重新导入。

</details>

## 订阅导入失败、无法更新或连接超时怎么办？

<details>
<summary>展开：先分清下载、解析和连接问题</summary>

### 1. 先确认复制的是订阅，不是注册链接

注册入口、登录地址和订阅地址不是同一种链接。从自己的账户页面复制适合当前客户端的订阅或配置，检查是否遗漏字符。不要随意改动其中的令牌和参数，也不要公开链接请别人代测。

### 2. 看错误发生在哪一步

| 现象 | 优先检查 |
|---|---|
| 下载订阅超时、域名无法解析 | 本地网络是否可用、服务方是否有公告、订阅地址是否变更 |
| 返回 401 | 凭证是否有效，订阅是否已撤销或需要重新获取；具体原因看服务说明 |
| 返回 403 | 服务器拒绝请求；核对服务规则并联系服务方，不把它直接等同于欠费或停运 |
| 返回 429 | 请求过于频繁；停止反复点击，按返回信息或服务说明等待 |
| 下载成功但解析失败 | 配置格式、客户端及内核是否兼容，返回内容是否实际上是登录或错误页面 |
| 导入成功但节点不能用 | 套餐状态、剩余流量、节点公告、当前选择的节点与分流规则 |

HTTP 状态码只能提供排查方向，不能替代服务方的具体解释。[401](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/401)、[403](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/403)、[429](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/429)

### 3. 按说明检查订阅更新所走的网络

订阅下载和实际节点连接可能走不同路径。例如 Mihomo 的代理集合可以指定下载或更新所用的代理。先看客户端与服务方说明，不要一遇到失败就同时改 DNS、路由、证书和多个代理开关；每次只改一项，方便确认原因。[Mihomo 代理集合配置](https://wiki.metacubex.one/config/proxy-providers/)

如果服务方明确规定订阅链接有有效期或更新次数限制，按它的规则重新获取；不要把某一家的限制当成所有订阅通用规则。重置订阅可能影响其他设备，操作前先确认。

### 4. 检查软件冲突，再提供脱敏日志

避免让多个客户端同时接管同一设备的代理或隧道。Android 的 VpnService 同一时间只允许一个活动 VPN 连接，新连接可能使旧连接停用。[Android 文档](https://developer.android.com/reference/android/net/VpnService)

仍无法定位时，整理系统、客户端版本、错误发生时间和报错内容发给可信客服或项目维护者。先删除日志中的订阅链接、令牌、密码、邮箱及其他个人信息。证书报错先检查系统时间、域名和服务公告，不要把关闭证书验证当作通用修复。

</details>

## 直连机场、中转机场和专线有什么区别？

<details>
<summary>展开：看实际路径，不只看线路名称</summary>

在本指南的线路描述里，“直连”指客户端直接连接出口节点，“中转”指先连接入口，再经其他节点转发。这是便于比较的约定；不同商家的命名未必一致。

直连不代表没有运营商路由，中转也不自动代表更快。判断体验时，要看用户到入口、入口到出口、出口到目标服务的完整路径。[OpenVPN 性能排查](https://openvpn.net/as-docs/v3/tutorials/tutorial--vpn-performance-troubleshooting/)

“专线”需要进一步问清：覆盖哪一段、使用什么连接方式、带宽是否独享、是否有明确服务承诺。正规私有互联本身也包括不同实现，不能凭标签推断全程独享。[Cloudflare 私有互联说明](https://developers.cloudflare.com/network-interconnect/)

即使其中一段使用私有链路，本地 Wi-Fi、宽带接入、设备负载和其他链路仍可能成为瓶颈。这是按端到端连接作出的判断，不是对表内任何商家线路的核验。[延迟的影响因素](https://www.cloudflare.com/en-gb/learning/performance/glossary/what-is-latency/)

没有线路证据时，本页只把“直连”“中转”“专线”视为服务方标注，不额外补写带宽、独享比例或可用性保证。

</details>

<a id="guide-test"></a>
## 机场测速怎么看：延迟、抖动、丢包与速度

<details>
<summary>展开：低延迟不等于高下载速度</summary>

| 指标 | 它主要说明什么 |
|---|---|
| 延迟 | 数据传输所需时间；常见 ping 显示的是往返时间 RTT |
| 抖动 | 延迟的变化程度，不同工具的统计方式可能不同 |
| 丢包率 | 在测试判定窗口内没有送达的数据包比例 |
| 吞吐速度 | 单位时间实际传输的数据量，与标称带宽并不等同 |

定义参考：[往返延迟](https://www.rfc-editor.org/rfc/rfc2681)、[时延变化](https://www.rfc-editor.org/rfc/rfc3393)、[丢包测量](https://www.rfc-editor.org/rfc/rfc2680)、[吞吐与性能排查](https://openvpn.net/as-docs/v3/tutorials/tutorial--vpn-performance-troubleshooting/)。

客户端里的“延迟”可能来自 TCP 连接或访问某个测试网址，先看测试方法和目标。不同软件、不同目标、不同网络测出来的数字，不宜直接排成同一张榜。

比较时尽量固定设备、接入网络、工具和测试目标，记录节点、协议、分流规则和时间。在常用时段多测几次，也留一份不经过该代理或隧道的基线，便于分清本地网络与线路因素。

除了下载速度，也看上传速度、空闲和负载下的延迟、抖动及丢包。单次峰值不能代表长期体验；到某个测速站很快，也不保证访问所有平台都一样快。[Cloudflare 测速方法说明](https://blog.cloudflare.com/how-does-cloudflares-speed-test-really-work/)

测速会产生真实流量，注意套餐额度和节点计费规则。看高清视频、视频会议、游戏的需求也不同；游戏还要确认 UDP 等协议支持，不能只凭下载速度判断。本文没有执行这些测试，因此不列“实测最快”或固定地域的绝对延迟下限。

</details>

## ChatGPT、YouTube、Netflix 能否使用或解锁？

<details>
<summary>展开：怎样核对平台可用性，而不是只看宣传</summary>

看到“支持 ChatGPT”“YouTube 4K”“Netflix 解锁”时，先问清测试日期、具体节点、设备、账号条件，以及究竟验证了什么。网页能打开、账号能登录、视频能播放和特定内容可观看，是不同结果。

### ChatGPT 能用，就代表账号一定可用吗？

不能这样判断。需要同时符合服务支持地区和账户规则；网络连通也不等于账号、付费功能或所有模型都可用。核对时以 OpenAI 当前说明为准，不把代理入口当作绕过服务限制的保证。[ChatGPT 支持的国家和地区](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)

### YouTube 能播放，就代表所有视频都能看吗？

不代表。具体视频可能受版权许可或所在地区规则限制。若讨论清晰度，应说明实际播放的视频、分辨率、设备和测试时间，而不是只凭节点名称写“稳定 4K”。[YouTube 地区播放限制说明](https://support.google.com/youtube/answer/92571?hl=zh-Hans)

### Netflix 解锁要看哪些条件？

确认使用自己的有效账户、所在地区及套餐条件，区分“能打开 Netflix”“能播放内容”和“能看到某部片”。Netflix 官方说明，使用 VPN 时可能只显示拥有全球授权的内容，而且含广告体验和直播存在额外限制；不要用一次测试承诺长期全区解锁。[Netflix 的 VPN 说明](https://help.netflix.com/en/node/114701)

如果以后加入实际测试记录，会单独写明日期、节点与测试范围；没有证据的项目保持未核验，不把服务方宣传改写成本站体验。

</details>
